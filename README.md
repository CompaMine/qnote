# QNotes — сервис одноразовых записок (One-Time Secret)

Самодостаточный сервис для обмена чувствительной информацией (пароли, токены, приватные данные). Текст шифруется в браузере (AES-GCM); сервер хранит только шифротекст и никогда не видит ключ и plaintext.

## Быстрый старт

```bash
docker compose up -d --build
```

Или одной командой после сборки:

```bash
docker build -t qnotes .
docker run -d -p 8443:8443 --name qnotes qnotes
```

В логах контейнера появится ссылка:

```text
✔ Сервис запущен: https://<ip>:8443
```

```bash
docker logs qnotes
```

Откройте URL в браузере. Используется **самоподписанный** HTTPS-сертификат — браузер покажет предупреждение (для MVP это ожидаемо).

### Переменные окружения

| Переменная    | По умолчанию | Описание |
|---------------|--------------|----------|
| `PORT`        | `8443`       | Порт HTTPS внутри контейнера |
| `PUBLIC_HOST` | автоопределение | Хост для ссылки в логах |
| `TLS_CERT`    | `/data/cert.pem` | Путь к сертификату |
| `TLS_KEY`     | `/data/key.pem`  | Путь к ключу |

Пример с явным хостом:

```bash
PUBLIC_HOST=192.168.1.10 docker compose up -d --build
```

## Как это работает

1. На главной странице (`/`) пользователь вводит текст и TTL.
2. Браузер генерирует случайный ключ AES-256 и шифрует текст (Web Crypto API).
3. На сервер уходит только шифротекст. Сервер возвращает `id`.
4. Пользователю выдаётся ссылка: `https://host:port/note/<id>#<key>`.
5. Фрагмент `#<key>` **не отправляется** на сервер по HTTP.
6. На странице просмотра кнопка «Показать» запрашивает шифротекст (atomic get-and-delete), расшифровывает локально и показывает текст один раз.

## Хранение

Записки хранятся **только в памяти** процесса. Без диска и без внешней БД.

> **Перезапуск контейнера = все записки теряются.** Это ожидаемое поведение.

Фоновый воркер удаляет записи с истёкшим TTL.

## Безопасность

- Ключ шифрования никогда не попадает на сервер
- Содержимое записок и ключи не пишутся в логи
- Get-and-delete атомарный (исключает двойной просмотр)
- Rate-limit на создание: 20 записок / IP / минута
- Максимальный размер шифротекста: 10 KB
- CSP, `X-Robots-Tag: noindex`, `Referrer-Policy: no-referrer`
- Кнопка «Показать» защищает от prefetch/ботов, сжигающих записку

## API

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/api/notes` | Создать записку `{ "ciphertext": "<base64>", "ttl": "once\|5m\|1h\|1d" }` → `{ "id": "..." }` |
| `GET` | `/api/notes/:id` | Получить и удалить шифротекст |
| `GET` | `/note/:id` | HTML-страница просмотра |
| `GET` | `/` | HTML-страница создания |

## Локальная разработка (без Docker)

Нужны Go 1.22+ и TLS-сертификаты:

```bash
mkdir -p data
openssl req -x509 -newkey rsa:2048 -nodes -keyout data/key.pem -out data/cert.pem -days 365 -subj "/CN=localhost"
TLS_CERT=data/cert.pem TLS_KEY=data/key.pem PORT=8443 go run .
```

## Что не входит в MVP

- Аккаунты / авторизация
- Персистентное хранилище
- Файлы и вложения
- Кластеризация (in-memory store не шарится между репликами)
